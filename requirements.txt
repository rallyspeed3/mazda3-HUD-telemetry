# ---- Everything below this line is NOT a pip package --------------------
# pip can't install these -- they're separate installs. Full walkthrough
# in docs/HARDWARE_SETUP.md, quick version here:
#
# 1. ffmpeg -- required by hud_overlay/render_overlay.py (it shells out to
#    the `ffmpeg` command to encode the video). Download from
#    https://ffmpeg.org/download.html and make sure it's on your system
#    PATH (test with `ffmpeg -version` in a terminal). Not needed if you
#    only want CSV logs, not rendered video.
#
# 2. Arduino IDE -- https://www.arduino.cc/en/software -- used to flash
#    any sketch in firmware/ onto either board.
#
# 3. If you're using an Arduino Uno + MCP2515: the arduino-mcp2515
#    library (by autowp) -- Tools -> Manage Libraries -> search
#    "mcp2515" -> install the one by autowp. Required to compile the
#    non-esp32_-prefixed sketches in firmware/.
#
# 4. If you're using an ESP32-S3 board instead: the "esp32 by Espressif
#    Systems" board package (Boards Manager, not Library Manager) --
#    see docs/HARDWARE_SETUP.md. No extra CAN library needed on this
#    board, the driver ships with the board package.
